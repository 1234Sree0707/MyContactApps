Developed a console based MyContactApp using basic OOPS concepts to manage contacts efficiently.

UC1
User registers by using his name, phone no, email.

UC2
Once user is registered, the user can now login either using basic Authentication(using username and password) or OAuth(Token).
For OAuth i have created a dummy system which authenticates the user.

UC3
Once logged in, User can now edit the profile information.

UC4
The user can now add contacts, and for each contact he can add name,phone number, and email.

UC5
Once user added contacts, the user can now view contacts and their details

UC6
User can now edit individual contact details

UC7
User can now delete individual contact

UC8
User can now perform bulk operation like delete, insert tag, or export contact into a txt file.

UC9
User can now search contact using keywords

UC10
User can now perform operations like filter based on date added, frequency etc.

UC11
User can now manage tags, like edit tags or combine it.

UC12
User can now assign multiple tags
